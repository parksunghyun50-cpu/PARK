# 🎮 가위바위보 게임

화려한 애니메이션과 함께 즐기는 웹 기반 가위바위보 게임입니다.

## 🎨 특징

- 다크 글래스모피즘 테마
- 부드러운 마이크로 애니메이션
- 실시간 점수 추적
- 연승 시스템 (3연승 이상 시 🔥 배너)
- 최근 10판 기록
- 키보드 지원 (1=가위, 2=바위, 3=보)
- 반응형 디자인

## ▶️ 실행 방법

`index.html` 파일을 웹 브라우저에서 열면 바로 플레이할 수 있습니다.

## 📁 파일 구조

```
├── index.html   # 메인 HTML
├── style.css    # 스타일 (다크 테마, 애니메이션)
└── script.js    # 게임 로직
```
